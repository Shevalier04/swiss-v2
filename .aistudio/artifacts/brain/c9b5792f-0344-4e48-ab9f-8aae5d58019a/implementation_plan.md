# 作业极简勾选导入与 TodayTab 动效升级计划

为解决控制台输入造成云端作业混乱、交互繁琐的问题，本方案全面落实“瑞士报刊极简风”交互减法：彻底移除模拟终端/控制台输入，改为高雅直观的“预设清单自由勾选导入”与“群通知智能识别粘贴”；实现同课程同标题作业的精准自动覆盖（Upsert），并在 TodayTab 中为今日课程卡片赋予优雅的微动效。

---

## 审查与关键决策 (User Review & Critical Decisions)

> [!IMPORTANT]
> 根据前序交互问答，已明确采纳以下产品与设计决断：

- **决断 1（控制台处理方式）**：已确认**完全移除控制台（Terminal/Console）输入模式**。取消所有人可随意通过终端向云端作业池注入数据的隐患，还原本周作业管理清晰、可信、干净的工具属性。
- **决断 2（作业导入交互流程）**：已确认**点击“导入作业”弹出作业清单模态框，用户可自由勾选目标作业后一键导入**。模态框内提供“全选 / 取消全选”、已存在条目高亮识别与覆盖提示。
- **决断 3（智能去重与覆盖 Upsert）**：当两条作业的 `course.trim().toLowerCase()` 与 `title.trim().toLowerCase()` 完全一致时，判定为同一项作业。导入时自动以最新截止日期与要求覆盖旧记录，并弹出精准反馈 Toast：`已成功导入 X 项作业（新增 A 项，覆盖更新 B 项）`。
- **决断 4（TodayTab 动效设计）**：采用瑞士排版克制优雅的微交互动效——课程卡片切入时具有轻微淡入（Fade In）与微妙上浮（Upward Float 4px~8px）的阶梯式入场，避免过度摇晃，保持报刊版式的庄重感。

## 1. 概述与核心目标 (Overview & Core Concept)

### 解决了什么问题
1. **去噪与安全**：原有的控制台文本解析虽然极客，但在学生日常使用中带来“谁都能改云端数据”的不安全感与认知负担。将其精简为“纯净勾选清单 + 智能微信群通知解析”双核引擎。
2. **拒绝盲目导入**：杜绝一键无脑塞入全部样例数据导致数据库脏乱，用户能够随时挑选自己真正选修的课程作业。
3. **数据一致性**：解决重复导入时产生多条冗余同名作业的问题，实现无缝覆盖更新。
4. **视觉质感提升**：今日课程作为用户打开频次最高的 Tab，加入平滑的卡片阶梯入场微动效，提升工具的高级质感。

## 2. 用户体验与视觉设计 (User Experience & Visual Design)

### 关键用户流程 (User Flows)
1. **浏览与触发导入**：
   - 作业页面顶部仅保留两个高频操作：【导入作业】与【智能识别】。
   - 作业为空时，空白卡片中央呈现“暂无待办作业”及高对比度的“从清单挑选导入”按钮。
2. **清单挑选导入模态框 (`HomeworkImportModal`)**：
   - 顶部：简短优雅的瑞士标题“导入课程作业”，副标题“选择需要加入本学期待办清单的作业项”。
   - 控制条：左侧“全选 / 取消全选”切换，右侧显示“已选 N 项”。
   - 列表项：
     - 左侧高对比度复选框，整行点击可轻松切换勾选。
     - 标题与课程名，右侧微标签：未导入的显示 `新作业`，已在当前作业列表中的显示醒目暖黄标签 `已存在 · 勾选将覆盖`。
   - 底部操作栏：主按钮“一键导入所选作业 (N 项)”，辅助取消按钮。
3. **智能识别粘贴模态框 (`SmartHomeworkPasteModal`)**：
   - 粘贴微信群通知文本后，解析出的清单同样支持每项复选，自动比对并标注 `新增` 与 `覆盖更新`，导入时仅提交勾选项目。
4. **反馈与沉淀**：
   - 导入成功后关闭弹窗，底部弹出报刊风格 Toast，清晰说明新增与覆盖更新的具体数量。
5. **TodayTab 今日课程微动效**：
   - 今日课程卡片渲染时附带 `animate-in fade-in slide-in-from-bottom-2` 样式与阶梯式微延迟（`animationDelay: ${idx * 60}ms`），让课程如报纸版面印刷般逐行展开。

### 视觉规范与暗黑美学 (Palette & Hierarchy)
- **基底背景**：`#181a1d` 与卡片 `#1f2227`，边框使用沉稳内敛的 `#33363d`。
- **高亮色调**：
  - 新增标识：冷灰米白 `#e9e4d8` 或清爽柔蓝。
  - 覆盖提醒：暖杏黄 `#d97706` / `text-amber-300` 配合深色底，警示却不刺眼。
  - 主按钮：纯黑底米白字 `#e9e4d8` 配精细边框，符合瑞士现代主义原则。

## 3. 核心设计决断与权衡 (Key Decisions & Trade-Offs)

| 决策点 | 采纳方案 | 权衡考量与原因 |
| :--- | :--- | :--- |
| **控制台输入** | **彻底移除控制台代码与UI** | 避免代码冗余与安全困惑，普通用户不需要命令行交互。 |
| **作业清单数据源** | **整合预设作业与云端池模态** | 将原本分散的预设作业（`SAMPLE_ASSIGNMENTS`）统一汇聚在勾选导入弹窗中，一次解决空数据引导与按需增补。 |
| **重复判定法则** | **课程与标题同时匹配 (大小写无关+首尾去空格)** | 比仅比对标题更精确，防止不同课程拥有同名作业（如“实验报告一”）时产生误覆盖。 |
| **动效实现技术** | **Tailwind 原生 CSS 过渡与微延迟** | 保持轻量零依赖，不增加外部繁重动画库，流畅支持低端手机与安卓设备。 |

### 涉及调整的核心文件与职责
1. `src/components/HomeworkImportModal.tsx`：移除 console 模式和所有控制台相关代码，重构为纯净的高雅勾选导入列表（含“全选/反选”、已存在作业状态徽章、所选项计数）。
2. `src/components/SmartHomeworkPasteModal.tsx`：传入 `existingHomework`，在已解析项列表显示 `新增` 或 `覆盖更新` 状态，仅提交已勾选项。
3. `src/components/HomeworkTab.tsx`：移除控制台入口按钮，将预设导入统一引导至勾选模态框。
4. `src/App.tsx`：健全 `handleBatchAddHw` 与 `handleImportPresetHw` 的 Upsert 比对与删旧建新逻辑，弹出准确的新增与覆盖数量统计 Toast。
5. `server/api.ts` & `functions/api/assignments.ts`：云端服务端接口同步强化同课程同标题 Upsert 去重，防止并发或脏数据。
6. `src/components/TodayTab.tsx`：为课程卡片容器增加 `@keyframes` 或 Tailwind `animate-in fade-in slide-in-from-bottom-2` 样式与阶梯式过渡。
