# 移动端/华为浏览器语音识别与一键权限重构方案

## 用户需求与痛点分析
1. **痛点一（语音未识别）**：移动端说话时动态声波虽然在跳动（麦克风硬件已收音），但结束时提示“云端引擎未检测到清晰发音”，且华为浏览器/鸿蒙设备始终无法正常识别。
   - **根因**：华为浏览器在 `MediaRecorder` 实现中封装的 WebM/MP4 容器存在时间戳头信息缺失与编码不标准问题，导致云端 API 解析出乱码或静音数据；同时后端/云函数对移动端带参 MIME 报错后触发了默认 fallback 提示。
2. **痛点二（权限指引繁重）**：之前的多步骤图文解除指引太长太繁琐，用户希望直接**“一键获取权限”**，点击按钮直接唤起系统授权并自动完成检测修复。

---

## 解决方案与技术架构

### 1. 通用无损 16kHz WAV 录音引擎（替代不可靠的 MediaRecorder）
- **技术原理**：不再依赖各手机浏览器内部碎片化的 `MediaRecorder`，而是采用所有现代手机浏览器（包括华为浏览器、iOS Safari、Chrome、微信等）均 100% 原生支持的 `AudioContext` 采样：
  - 自动将音频重采样为语音识别行业标准的 **16,000 Hz 单声道（Mono）**；
  - 采集高保真 16-bit PCM 数据，并在客户端直接封装为标准的 **44 字节 RIFF WAV 文件头**；
  - 输出格式统一为纯粹的 `audio/wav`。
- **核心收益**：
  - **彻底解决华为浏览器兼容性**：完全避开华为 WebM 容器格式缺陷；
  - **云端识别率大幅提升**：无损 PCM 音质，Gemini 模型对 `audio/wav` 的识别准确率与响应速度达到最佳；
  - **体积轻量**：16kHz 单声道 16-bit 每秒仅 32KB，传输极快且零丢失。

```
┌────────────────────────┐
│ 手机麦克风（声波跳动） │
└───────────┬────────────┘
            │ getUserMedia()
            ▼
┌───────────────────────────────────────────────┐
│ AudioContext (16kHz 重采样 + 单声道 PCM)       │
└───────────┬───────────────────────────────────┘
            │
            ▼
┌───────────────────────────────────────────────┐
│ 客户端直出标准 44-byte RIFF WAV (audio/wav)    │
└───────────┬───────────────────────────────────┘
            │ Base64 极速传输
            ▼
┌───────────────────────────────────────────────┐
│ 服务端双引擎转录: gemini-3.5-transcribe ➔ 3.8  │
└───────────┬───────────────────────────────────┘
            │
            ▼
      高精度文本秒级上屏！
```

---

### 2. 权限开启流程简化为“一键唤起与自动重测”
- **权限简化重构**：
  - 移除大段需要用户手动翻找设置的繁琐步骤；
  - 核心操作置顶为醒目大按钮：**「一键获取麦克风 / 通知权限」**；
  - 点击直接调用原生 `Notification.requestPermission()` 或 `getUserMedia()` 唤起系统授权浮窗；
  - 授权完成后自动重测，检测通过立即提示“🎉 权限已成功获取”并自动关闭，无需繁琐阅读；
  - 仅在用户误触“永久禁止”时，提供折叠式的精简辅助说明。

---

### 3. 服务端与双模型智能重试
- 在 `server/api.ts` 与 `functions/api/ai/transcribe.ts` 中优先匹配 `audio/wav`；
- 首选 `gemini-3.5-transcribe` 进行高精度转录；若出现异常，毫秒级无缝自动切换至 `gemini-3.8-flash` 多模态引擎，确保无论网络与环境如何均稳定输出识别文本。

## 验证与测试计划
1. **构建与类型验证**：运行 `compile_applet` 和 `lint_applet` 确保 TypeScript 零报错。
2. **WAV 录音与格式验证**：
   - 验证音频二进制头是否包含标准的 `RIFF`、`WAVE`、`fmt ` 标识及 16kHz 16-bit 参数；
   - 验证录制后发送给后端的 MIME 为 `audio/wav`；
3. **华为浏览器/移动端语音识别链路测试**：
   - 验证短语输入（如“高数课后习题明天交”），检查转录返回结果与智能作业要素解析；
4. **一键权限测试**：
   - 测试点击一键授权按钮直接唤起系统原生弹窗与自动重检流程。
