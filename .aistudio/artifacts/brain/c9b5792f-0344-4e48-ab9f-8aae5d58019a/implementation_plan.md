# 全班 42 名学生接入作业下发与同步看板实施计划

## 1. 用户需求与确认要点
- **功能目标**：将作业发送与管理终端中的学生名册扩充至班级全部 42 名同学（含 `2612114501` 至 `2612114541` 及 `2512114511`），实现全班全员覆盖。
- **覆盖范围（基于答复）**：全域全量同步，包括：
  1. **管理终端（AdminTerminalModal）**学生账号管理列表；
  2. **作业同步看板（Sync Dashboard）**可视化图表进度矩阵；
  3. **一键下发作业（Broadcast）**与 D1 数据库分发通道。
- **展示与交互组织（基于答复）**：采用**紧凑滚动列表**搭配**搜索过滤框（Search Filter）**，支持按姓名或学号快速检索 42 名学生中的任意一位。
- **下发行为（基于答复）**：点击一键下发时，直接向全班 42 名同学全量同步作业，并在终端与看板中实时更新每位同学的接收状态。

---

## 2. 详细技术方案

### A. 全班 42 名学生名册统一管理 (`src/utils/studentRoster.ts` & `src/services/api.ts`)
1. **统一名册导出 (`ALL_STUDENT_LIST`)**：
   - 在 `src/utils/studentRoster.ts` 中基于已有的 `STUDENT_ROSTER` 导出标准的 42 名学生数组 `ALL_STUDENT_LIST: { username: string; name: string }[]`。
2. **管理端数据概览与离线同步 (`src/services/api.ts`)**：
   - `getAdminOverview()`：使用 `ALL_STUDENT_LIST`，保证返回完整的管理员与 42 名同学名单；
   - `pushHomeworkToAllStudents()`：向全班 42 名同学批量注入作业，并更新每位同学的作业统计计数。
3. **Cloudflare D1 后端全员下发 (`functions/api/homework/console-pool/index.ts` & `functions/api/admin/overview.ts`)**：
   - 将 D1 下发目标拓展为完整的 42 名学号列表，确保写入 Cloudflare D1 `assignments` 时所有同学均被下发并隔离存储。

### B. 管理终端与同步看板体验升级 (`src/components/AdminTerminalModal.tsx`)
1. **大盘指标统计更新**：
   - 官方作业基准数：`14 项`
   - 全班学生基数：`42 人`（完全同步达标统计变更为 `X / 42 人`）；
   - 全员下发率与平均完成率基于 42 名同学动态加权计算。
2. **看板搜索与紧凑排版**：
   - 在「作业同步看板」中增加轻量级搜索输入框：支持即时按**学号**（如 `4508`）或**姓名**（如 `谢炟荣`）过滤；
   - 优化学生进度条卡片内边距与字号，支持高密度流畅滚动浏览；
3. **全员广播链路实时反馈**：
   - 点击「⚡ 一键下发作业」，终端输出打出全班 42 名同学的逐个投递成功日志，看板进度条实时平滑递增至 100%。
