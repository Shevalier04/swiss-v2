# AdminTerminalModal 作业同步完成率可视化图表实施计划

## 1. 用户需求与确认要点
- **功能目标**：在管理终端（AdminTerminalModal）中引入可视化图表看板，直观监控一键下发作业后的各学生账号作业同步进度与完成情况。
- **图表形态（基于答复）**：采用**水平双轨进度条（Horizontal Progress Bars）**搭配高对比**百分比数据徽章（Percentage Badges）**。
- **布局位置（基于答复）**：在底部管理面板中，新增独立的**「📊 作业同步看板 (Sync Dashboard)」**选项卡，与“全班学生账号”和“控制台作业库管理”并列。
- **监控指标（基于答复）**：同时可视化呈现**“广播下发同步率”**（学生已接收作业量 / 官方池总作业量）与**“作业实际完成率”**（已完成作业 / 已分配作业）。

---

## 2. 详细技术方案

### A. 状态与面板导航扩充 (`src/components/AdminTerminalModal.tsx`)
1. **选项卡类型扩充**：
   - 将 `panelTab` 类型扩展为 `'users' | 'hw' | 'chart'`，默认依然可在三者间无缝切换；
   - 在面板顶部导航栏新增按钮：
     - 图标：`BarChart3`
     - 标签：`📊 作业同步看板`
     - 支持右上角一键刷新与联动。

### B. 看板可视化组件设计 (`src/components/AdminTerminalModal.tsx`)
1. **班级大盘指标概览（KPI 卡片群）**：
   - **官方池基准作业**：展示当前官方作业库总条目数（例如 14 项）；
   - **全班平均下发率**：计算全班学生平均同步下发百分比；
   - **全员达标学生**：显示已 100% 接收官方池作业的学生人数（如 10/10 人）；
   - **平均完成进度**：全班已提交/完成作业的整体推进百分比。
2. **逐生水平进度条矩阵（Student Progress Matrix）**：
   - 每行对应一名学生（学号、姓名、角色标签）：
     - **下发同步率条（蓝色光轨 `from-[#6b7cff] to-[#8ea4ff]`）**：
       - 计算公式：`deliveryRate = Math.min(100, Math.round((assignedCount / poolCount) * 100))`
       - 包含动态进度条与 `X% (已收 N/总 M 项)` 徽章；
     - **实际完成进度条（翡翠绿轨 `from-[#10b981] to-[#34d399]`）**：
       - 计算公式：`doneRate = Math.round((doneCount / assignedCount) * 100)`
       - 包含动态完成度条与 `X% 已完成` 徽章；
3. **实时动效与联动**：
   - 进度条宽度使用 CSS 平滑过渡（`transition: width 0.5s ease-out`）；
   - 点击「⚡ 一键下发作业 (广播测试)」后，图表数据即时响应，同步率实时拉满至 100%，提供极强的一目了然视觉反馈。

   - 点击顶部快捷栏「⚡ 一键下发作业」，观察下发率进度条平滑递增至 100% 满格，徽章动态更新；
   - 确认无样式溢出与卡顿。
